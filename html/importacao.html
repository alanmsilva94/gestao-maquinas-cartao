Importar e atualizar bases

As planilhas originais nunca são alteradas: o sistema lê só as colunas necessárias e guarda uma cópia neste navegador.

Este navegador não oferece acesso direto a arquivos (File System Access API). Para atualizar, selecione as planilhas novamente. Para vincular arquivos e gravar direto na planilha, use Chrome ou Edge.

Arraste aqui as planilhas (.xlsx) ou clique para selecionar

Pode soltar as três de uma vez — o tipo de cada uma é reconhecido pelos cabeçalhos das colunas.
